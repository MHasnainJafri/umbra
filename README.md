# Umbra

Public pages for **Umbra**, a video player with a private, encrypted vault for Mac, iPhone, iPad and Android.

- Website: https://mhasnainjafri.github.io/umbra/
- Privacy policy: https://mhasnainjafri.github.io/umbra/privacy.html
- Terms of use: https://mhasnainjafri.github.io/umbra/terms.html
- [`libvlc-source/`](libvlc-source/): the exact scripts, configuration and patches Umbra uses to build
  libVLC (VideoLAN, LGPL 2.1 or later), so anyone can rebuild it and use their own build.

Questions or problems: open an issue. Issues are public — never post a vault password, recovery kit or
anything personal.

Umbra's own app code is not open source; only the files in this repository are published.
